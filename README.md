## Online Library System
This project is a proof of concept of an online library backend for a public catalogue where users can search books by
- Title
- Author
- ISBN
- Age rating
- Genre
- Custom Tags
- Availability
- Language

Created using the Rust Axum and Diesel libraries for API and database functionality
